# Master Engineering Blueprint: `cleanOCR` (v1.1)**A Rust-Native Smart OCR, MRC Compression, & Semantic Document Reconstruction Engine**Execute **one milestone at a time**. Do not advance to Milestone N+1 until every automated verification gate in Milestone N passes cleanly.---## 1. System Overview & Architectural Invariants`cleanOCR` ingests raw document pages (existing PDFs, raster scans, camera photos, and—in Phase 2—network scanners via eSCL) and compiles them into a **3-Layer Semantic Sandwich** backed by a single **Canonical Document IR (JSON/AST)**:1. **Visual Ground Truth Layer (MRC-Compressed or Full Raster):** Preserves 100% visual fidelity of fonts, wet signatures, stamps, and paper texture while shrinking scanned pages by 5x–15x via Mixed Raster Content (Background + Foreground + 1-bit JBIG2 Mask).2. **Invisible Pixel-Aligned Semantic Text Layer:** Stores structured headings, multi-column paragraphs, tables, lists, and LaTeX math (both display and inline)—each anchored to exact bounding boxes on the visual layer.3. **Isolated Figure & Asset Layer:** Stores cropped high-clarity figures, charts, logos, optional SVG-traced seals/signatures, and (in Tier 2+) structured `ChartIr` data linked to captions.### Non-Negotiable Engineering Invariants1. **Single Source of Truth:** **NEVER** scrape HTML to produce `.tex`, `.md`, or `.docx`. Every exporter (`html`, `pdf`, `tex`, `md`, `docx`) MUST compile strictly from `DocumentIr` + `PageVisualAssets`.2. **Coordinate System Law:** Inside `cleanocr-ir`, all bounding boxes use **normalized top-left origin coordinates** in `[0.0, 1.0]` (`x0 < x1`, `y0 < y1`). Conversion to pixel coordinates happens only in `ingest`/`vision`/`mrc`; conversion to bottom-left PDF points (`y_pdf = page_h - y_top`) happens **exclusively** inside `cleanocr-export` (`pdf.rs`).3. **Zero Silent Legal Corruption:** Default JBIG2 compression MUST use `Jbig2Config::lossless()`. Lossy symbol-dictionary mode (`Jbig2Config::text()`) is strictly opt-in behind `--compression-profile book-max`.4. **Never OCR Crisp Digital PDF Text:** For digital-born PDFs with valid Unicode text streams, extract native text spans directly and use vision models only for layout/reading-order/table/formula grouping.5. **CPU/ML Isolation:** Never run ONNX inference, Sauvola binarization, or JBIG2 encoding on a `tokio` async worker thread. Wrap heavy CPU/ML work in `rayon` pools or `tokio::task::spawn_blocking`.6. **Self-Contained Re-Exportability:** Both the Layered HTML output and the Hybrid PDF/A-3 output MUST embed the serialized `DocumentIr` JSON so archived files can later be re-exported losslessly to `.tex`, `.md`, or `.docx` without re-running OCR.7. **Deterministic LaTeX Compile Safety:** Every formula string MUST pass `validate_latex_math()` before being emitted as raw TeX; invalid formulas MUST gracefully fall back to their cropped PNG asset (`DisplayFormula`) or escaped plain text (`inline_math_latex`). For data charts, **never** let an LLM write raw `pgfplots` syntax directly—always populate `ChartIr` and compile via deterministic Rust templates.---## 2. (`crates/cleanocr-ir/src/reading_order.rs`)Implement **Recursive XY-Cut** as a deterministic sorter/validator:1. Extract `HeaderFooter` blocks first (`y1 < 0.08` or `y0 > 0.92`) so running headers never interrupt body text flow.2. Project remaining block bounding boxes onto X-axis and Y-axis.3. Find the widest whitespace valley (gutter) wider than `min_gutter = 0.025`. Prefer horizontal cuts across full-width banners/titles, then vertical cuts for multi-column bodies, then top-to-bottom within each column.4. Assign sequential `reading_order` and `column_index`.---### Crate 2: `cleanocr-ingest` (Unified Input & Preprocessing)#### Core Trait (`src/source.rs`)```rustpub struct RawPage {    pub page_index: usize,    pub rgb_image: image::RgbImage,    pub dpi: u32,    pub width_pt: f32,    pub height_pt: f32,    pub native_text: Option<Vec<NativeTextRun>>,}pub trait PageSource: Send {    fn source_name(&self) -> String;    fn source_sha256(&self) -> String;    fn next_page(&mut self) -> anyhow::Result<Option<RawPage>>;}```#### Smart PDF Router (`src/pdf.rs`)For every page of an input `.pdf`:1. Render at target DPI (default 300 DPI) via `hayro` to produce `rgb_image`.2. Inspect native text operators (`Tj`, `TJ`) and `ToUnicode` CMap validity via `lopdf` / `hayro-syntax`.3. **Sanity Gate:** Reject native text if more than 10% of extracted characters are `\u{FFFD}`, private-use-area glyphs (`U+E000..U+F8FF`), or non-whitespace control chars.4. Classify each page: `ScannedRaster`, `DigitalNativeText`, or `HybridNativePlusOcr`.#### Image Preprocessing (`src/preprocess.rs`)Run ONLY on `ScannedRaster` or camera images:1. **Orientation Correction:** 0° / 90° / 180° / 270° via `oar-ocr` orientation classifier.2. **Fine Deskew (±15°):** Projection-profile variance over `-15°..+15°` in 0.5° steps, refined in 0.1° steps; rotate with paper-median border fill.3. **Illumination Normalization:** Estimate smooth background lighting via downsampled morphological closing / box blur (`sigma ~ 35px` at 300 DPI), then compute `normalized = clamp(img / bg_estimate * paper_white)`.---### Crate 3: `cleanocr-vision` (Layout, OCR, Tables, Inline/Display Math, & 3-Tier Graphs)Define a mockable `VisionBackend` trait so unit tests run offline without downloading ONNX weights. `inline_formula` box, crop from the 300 DPI RGB image (padded by 4px) and run `PP-FormulaNet` / `UniMERNet`.2. **Display Formula Fallback Asset:** For every `DisplayFormula` block, ALWAYS save its cropped PNG under `PageVisualAssets::figures` and store its key in `fallback_asset_id`.3. **Inline-Math Span Anchoring (No Text Duplication):**   * Match each `inline_formula` bounding box to its enclosing `TextLine` (vertical overlap `> 50%` of inline box height).   * Remove any plain OCR or native PDF `TextSpan` inside that `TextLine` whose intersection with the `inline_formula` box exceeds `50%` of the span's area, then insert a single `TextSpan` with `inline_math_latex: Some(cleaned_latex)` (stripping enclosing `$`, `\(`, `\)`), `text: original_text`, and `source: TextSource::FormulaModel`.   * Re-sort `line.spans` strictly left-to-right by `bbox.x0`.4. **Dense-Math Heuristic Trigger:** If a `TextLine` has zero `inline_formula` boxes from layout detection, scan its OCR text for 2+ math Unicode symbols (`? ? ? v = = ? ± × 8 a ß ? d ? ? µ s p ? O`), caret/underscore sub/superscripts, or isolated single-letter italic variables next to `=` or `+`. Crop and run formula recognition; accept if confidence `>= 0.85` AND `validate_latex_math()` passes.#### 3-Tier Graph & Figure Strategy (`src/assets.rs`)* **Tier 1 (Default — M1–M5):** Crop every `Figure` block cleanly into `PageVisualAssets::figures` as PNG. For `Signature` or `SealOrStamp`, separate foreground ink via Lab distance (`?E > 18`), set paper alpha to `0`, and optionally trace via `vtracer` (`filter_speckle = 4`) with a **60 KB / 1,500 path segment complexity guard**. Leave `chart_data: None` and `tikz_source: None`.* **Tier 2 (Phase 2 Opt-In — `--charts pgfplots`, feature `chart-vlm`):** Populate `ChartIr` via chart VLM and ALWAYS emit a `ConfidenceWarning` (`"Chart values extracted via ML; verify numbers before publication"`).* **Tier 3 (Phase 3 External Plugin — `--diagrams tikz`):** Optional plugin hook that populates `tikz_source` ONLY after sandboxed `lualatex` verification.---### Crate 4: `cleanocr-mrc` (Mixed Raster Content Layer Splitter)1. **Photo Protection Mask:** Rasterize all `Figure` bounding boxes (padded inward 2px) into `photo_mask: Vec<bool>`. Force `mask[i] = 0` inside photo regions.2. **O(1) Integral-Image Sauvola + Colored-Ink Capture (`src/binarize.rs`):** Compute 64-bit summed-area tables (`sum`, `sum_sq`) on luminance (`W = 31`, `k = 0.25`, `R = 128.0`), plus Lab/RGB distance from coarse paper-white (`distance > 22.0 && !photo_mask[i]`) to capture colored stamps/headers. Despeckle 1–2 px dust.3. **Halo-Free Pull-Push Inpainting (`src/inpaint.rs`):** Fill text holes in `BG` (`!mask`) and dilate ink colors in `FG` (`mask`) via multi-scale mipmap Pull-Push pyramid + 3 passes of 3x3 masked box blur BEFORE downsampling.4. **Downsample & Encode:** Resize `BG` to 1/2 (`zune-jpeg`, Q75), `FG` to 1/3 (`zune-jpeg`, Q65), pack binary `mask` MSB-first per row and encode via `jbig2enc_rust::encode_single_page(&packed, w, h, &Jbig2Config::lossless())` (plus 1-bit PNG for HTML).---### Crate 5: `cleanocr-export` (Five Deterministic Exporters)* **HTML5 (`src/html.rs`):** Self-contained `.html` with Replica vs. Reader mode toggle, layer checkboxes, and embedded `<script type="application/json" id="cleanocr-ir">` (`</` escaped as `<\/`).* **PDF/A-3 (`src/pdf.rs`):** `pdf-writer` v0.15.0 with 3 OCG layers (`Background`, `Foreground_Ink`, `Figures_Overlays`), JBIG2 `/Mask`, invisible pixel-aligned text (`3 Tr`), embedded Unicode TrueType font + `ToUnicode` CMap, and attached `cleanocr-ir.json` (`/AFRelationship /Data`).* **Semantic LaTeX (`src/latex.rs` + `src/latex_math.rs` + `src/latex_pgfplots.rs`):**  * Target LuaLaTeX/XeLaTeX (`fontspec`, `amsmath`, `amssymb`, `graphicx`, `booktabs`, `multirow`, `multicol`, `hyperref`).
