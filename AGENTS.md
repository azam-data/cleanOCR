# AGENTS.md — Repository Rules for Antigravity## 1. Communication & Quota Efficiency Rules (Lite Mode)- Be concise and direct. Skip filler intros, pleasantries, and restating the prompt.- Summarize completed changes in <= 6 short bullet points with file paths and passing test counts.- Read `BLUEPRINT.md` once at the start of a task, then inspect only the files relevant to the active milestone.- Batch related file edits together and run targeted `cargo test -p <crate>` before running full workspace checks.- Execute **one milestone at a time** from `BLUEPRINT.md`. Never start Milestone N+1 until all Milestone N verification gates pass.## 2. Mandatory Build & Verification CommandsBefore marking any task complete, run:1. `cargo fmt --all -- --check`2. `cargo clippy --workspace --all-targets -- -D warnings`3. `cargo test --workspace`## 3. Non-Negotiable Architectural Invariants1. **Single Source of Truth:** NEVER scrape HTML to generate `.tex`, `.md`, or `.docx`. All 5 exporters MUST compile strictly from `DocumentIr` + `PageVisualAssets`.2. **Normalized Top-Left Coordinates:** Inside `cleanocr-ir`, all `BBox` coordinates use normalized top-left origin `[0.0, 1.0]` (`x0 < x1`, `y0 < y1`). Convert to bottom-left PDF points (`y_pdf = page_h - y_top`) ONLY inside `cleanocr-export/src/pdf.rs`.3. **Zero Silent Legal Corruption:** Default JBIG2 compression MUST use `Jbig2Config::lossless()`. Lossy symbol-dictionary mode (`Jbig2Config::text()`) is strictly opt-in behind `--compression-profile book-max`.4. **Never OCR Crisp Digital PDF Text:** When `PageIngestMode::DigitalNativeText` is detected, trust native PDF Unicode text spans directly and use vision models only for layout, reading order, tables, formulas, and figures.5. **CPU/ML Isolation:** Never run ONNX inference, Sauvola binarization, or JBIG2 encoding directly on a `tokio` async worker thread. Wrap heavy CPU/ML work in `rayon` pools or `tokio::task::spawn_blocking`.6. **Self-Contained Re-Exportability:** Both HTML and PDF/A-3 outputs MUST embed serialized `DocumentIr` JSON so `cleanocr convert-ir` can re-export to `.tex`, `.md`, or `.docx` with zero re-OCR.7. **Deterministic LaTeX Compile Safety:** Every formula string MUST pass `validate_latex_math()` before raw emission; invalid formulas fall back to `fallback_asset_id` PNG (display) or escaped plain text (inline). Never let an LLM emit raw `pgfplots` syntax—always populate `ChartIr` and compile via `latex_pgfplots.rs`.## 4. Critical Anti-Patterns Checklist- **PDF Y-Axis Flip:** Always compute `y_pdf = page_height_pt - (bbox.y1 * page_height_pt)` in `pdf.rs`. Verify with a unit test that top-of-page headings land at `y_pdf > 0.8 * page_height_pt`.- **JBIG2 Bit Polarity:** `jbig2enc-rust` expects MSB-first packed bits, byte-aligned per row (`1 = ink`, `0 = background`).- **Inpaint Before Downsampling:** Always run Pull-Push inpainting on `BG` and `FG` at full resolution BEFORE downsampling/JPEG encoding to eliminate dark halos around letters.- **Formula Escaping:** Never double-escape validated LaTeX math; never emit unvalidated raw math. Handle `\\}` properly in `validate_latex_math` (`\\` is a line break, not an escaped brace).- **Inline Math Deduplication:** When replacing OCR spans with an `inline_formula` span inside a `TextLine`, remove overlapping plain spans (`intersection > 50%` of span area) before inserting and re-sorting by `bbox.x0`.- **HTML Script Injection Guard:** Replace `</` with `<\/` when embedding `DocumentIr` JSON inside `<script type="application/json">`.- **`ort` v2.0.0-rc.14+ Init:** Build `Environment` explicitly (`let env = ort::init().build()?;`) and pass `&env` to `Session::builder(&env)?`.- **Offline CI:** Mock the `VisionBackend` trait in unit tests so `cargo test` runs in seconds without downloading ONNX model weights.
